# StellaMod

## How to install:

Step 1: Clone repository (branch midterm) (you can also use the download as zip feature.)

Step 2: Create a directory named "stella" in your Quake 4 folder.

Step 3: Move game000.pk4 and pak001.pk4 to the "stella" folder.

Step 4: Move the StellaMod shortcut into your Quake 4 folder.

Step 5: Use the StellaMod shortcut to launch the game and click Help for instructions on how to access the new features.

## How to compile:

Step 1: Clone repository

Step 2: Install Visual Studio 2022 with the C/C++ tools:

Step 3: Compile idlib and game (in that order.)

Step 4: Use the provided game000.pk4 pak file and add the compiled gamex86.dll to that archive, deleting the old one.

## How to use mod features:

Read ingame help screen.
